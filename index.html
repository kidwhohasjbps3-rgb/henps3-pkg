C'est quoi le HEN ?

Le HEN (Homebrew Enabler) permet de lancer du code non signé sur n'importe quel modèle de PS3 (Fat, Slim, Super Slim) sans risque de "brick".

🛠️

Outils Requis

  • Une clé USB (FAT32)
  • Le firmware HFW 4.90/4.91
  • Un PC pour préparer les fichiers
📦

Indispensables

Une fois hackée, installez MultiMan ou WebMan pour gérer vos jeux et contrôler la ventilation de la console.
